# New World：产品路线图

> 状态：活跃。最后更新 2026-11-09（独立仓库 v0.1.0）。
>
> 产品定位：以**角色演绎**为核心的沉浸式对话产品。整个数据库就是硬盘上的一个
> 文件夹；每个世界是库里一个子文件夹、由几个 Markdown 文件组成。配一个
> OpenAI 兼容模型端点后可让 AI 从一句话生成整个世界，离线时走本地剧本回复。
> 界面是「角色中心」的，而不是地图/任务/功能面板。

## 已完成（v0.1.0 及之前）

### 世界与数据
- [x] 文件夹数据库：一个世界 = 一个子文件夹，`world.md` + `characters/*.md`
      + `world_book.md` + `conversations/*.json` + `events.json`，全部可读可改。
- [x] 手写 JSON codec（`scenario_codec.mbt`），解析全容错：单文件坏只降级该文件。
- [x] 跨刷新授权：授权过的世界库记在 IndexedDB，刷新不用重选。
- [x] 增量写入（`effect.mbt` 的 `CommitScope`）：只重写触碰的对话 + 事件，
      不再全量重写整个世界。
- [x] 世界导出 / 导入：单个 `.aiworld.json`（含立绘），导入永远新建文件夹。
- [x] 对话与事件日志 JSON 落盘（`journal.mbt`），并按角色分文件（支持分支）。

### 角色
- [x] 六区块角色卡 v2：人设 / 外貌 / 说话方式 / 目标 / 秘密 / 位置，并扩展出
      行为原则、示例台词、与用户的关系、当前情境、开场白、记忆规则。
- [x] 分区式角色编辑器：七个分区一次只看一个，整页不透明，保存/取消明确。
- [x] 人物立绘：`characters/<名>.png` 与卡片同目录，卡片只存文件名；名单圆形
      小头像 / 舞台方形头像，无立绘回落到色块 + 首字。
- [x] Tavern v2 角色卡：导出为 SillyTavern 可读格式，可反向读入，PNG `tEXt`
      块也能读（`tavern_card_from_png`）。

### 对话与模型
- [x] 双回复路径：有 key 走 OpenAI 兼容端点；无 key 走本地剧本（离线可玩）。
- [x] 请求携带完整消息序列：人设系统提示 → 「此前」摘要 → 世界书命中 →
      预算内历史 → 玩家这一句，多轮连贯。
- [x] 上下文预算与记忆压缩：超预算时最老片段压写成「此前」摘要随请求携带。
- [x] 角色记忆簿（`characters/<名>.memory.md`）：可固定/删除、可标「不进
      上下文」、可带「进展:主题」（同主题只留最新一条进上下文）；模型提议
      需人工采纳。
- [x] 流式输出（SSE）：字一边写一边出现在舞台；不支持流式的整段照样回来。
- [x] 看得见的提示词：抽屉「提示词」面板展示这一轮真正发给模型的内容，
      与发送走同一套装配（同一个 `plan_messages`）。
- [x] 说 / 做 / 旁白 / 这一幕（Beat）四种输入意图，单输入框 + 模式切换 +
      组合态多段合成一轮。
- [x] 对话编辑：重新生成（旧回复变候选 swipe）、改 / 删 / 清空、分叉
      （同级文件 `conversations/<角色>~N.json`）。
- [x] 世界书命中可见：命中几条显示在对话末尾。

### 世界与场景
- [x] AI 生成世界：一句话设定 → 背景叙述、人物卡、世界书、地图地点。
- [x] 世界书（Lorebook）：`[priority] [position] [recursion] [probability]`
      修饰符；离线剧本走同一套选取逻辑。
- [x] 场景多角色同场：同地点 ≥2 人时进入同一段对话，每行标出是谁说的；
      按回合顺序轮流回应，不额外花一次模型调用决定谁说话。
- [x] 显式时间推进：「推进时间」按钮让模型写一段「这段时间发生了什么」，
      是显式动作而非后台定时器。

### 界面
- [x] 角色中心重构：角色 rail / 舞台 / 小说式转录（角色正文不装气泡，
      玩家消息轻气泡）。
- [x] 按需抽屉：档案 / 记忆 / 模型状态 / 事件 / 提示词 / 世界书，五个以上面板。
- [x] 全屏氛围视图（地图 + 氛围切换）与低干扰背景。
- [x] 宣纸（浅）/ 墨蓝（深）双主题，一键切换。
- [x] 自适应布局：Wide（≥1080）/ Medium（≥760）/ Compact（手机竖屏），
      布局是视口的纯函数。
- [x] 长会话不卡：记录只建最近 40 行，更早的用「更早的对话」翻出；滚动锚点
      用「最新一行的文本」。
- [x] 消息「更多」菜单：重生成 / 候选 / 改 / 删 / 分叉。

### 工程
- [x] 纯 TEA：`update` 是纯函数，注入 `TurnRunner`（provider）与 `WorldHost`
      （文件 IO），失败永远只是事件面板一条提示。
- [x] 纯性护栏（`purity_wbtest`）：全部 `Msg` 变体不写穿入参。
- [x] 落盘性质护栏（`roundtrip_wbtest`）：`reload ∘ commit` 保持状态。
- [x] 死 UI 闸门：`msg.mbt` 与 `update.mbt` 分离，让构造点可被扫描。
- [x] 跨平台复用：Web（wasm-gc + WebGPU / Canvas2D 回退）与 macOS（Skia）共用
      同一个 `app` 包。
- [x] **毕业为独立仓库**（2026-11-09，原 `examples/new_world` in MoUI）。
- [x] 326 项测试全绿；`moon test app --target native`、`moon build web_wasm
      --target wasm-gc`、`moon build macos_skia --target native` 均通过。

### P1：产品打磨
- [ ] 角色记忆按相关性注入的调优：现在按「主题最新一条进上下文」，进一步按
      与当前场景/话题的相关性排序与截取，而非固定顺序。
- [ ] macOS 原生路线打磨：字体渲染、窗口尺寸自适应、目录选择器与 Web 一致。
- [ ] 立绘 AI 生成：把现在只产出「立绘提示词」（`appearance` 字段）升级为可选
      的图像 API 调用（保留人工粘贴路径）。

### P2：可玩性扩展
- [ ] 多世界并行：同一库里同时打开多个世界，跨世界切换不丢未发送草稿。
- [ ] 会话存档：把一个会话导出为可再演入的剧本文件（不仅是 `.aiworld.json`）。
- [ ] 角色关系随时间演化：关系字段 + 记忆规则联动，让「称呼/态度」随剧情变化。

## 非目标（明确不做）
- 地图/任务/战斗系统作为核心界面——产品是「角色中心」的，地图只是氛围视图。
- 多模态图像生成作为默认依赖——生成世界只产出提示词，图片走人工粘贴。
- 云端账号体系——数据库就在用户的硬盘上，配置 `config.json` 留在世界库根目录。
